# gabrielgomez1100.github.io
Sound Amplification: Record your audio signals using your computer or phone and save the signal files to your computer. Using python, amplify specific frequencies in your audio file (that is, you don’t just want to increase the volume, instead you’d want to amplify a particular type of sound). Graph the frequencies that you selected to amplify, the fluctuations, and the intensity levels in dB. If time permits, build a transistor amplifier for a speaker and by tuning the amplification circuit, try to mimic the same amplification on hardware. Gabriel Gomez
